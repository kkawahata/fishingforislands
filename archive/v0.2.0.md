# v0.2.0 — Contiguous islands + rapid-update protocol
Date: 2026-04-22

## Summary
The world is now one solid landmass. Islands were previously separate
platforms connected by wooden bridges; with this update every non-turtle
island is size 8 and sits on a uniform 8-unit grid so edges touch
directly. The turtle is doubled to size 12 and pushed 8 units west into
the water, reached by the only remaining bridge.

This version also introduces the rapid-update protocol (see
`archive/README.md`) and a small version chip under the day counter so
playtesters can name the build they're looking at.

## Changes

### Contiguous map
- `src/data.js` — new `ISLAND_SPACING = 8`, new `getIslandWorldPos` and
  `getTurtleBridgeBand` helpers so placement math lives in one place.
  Turtle `size: 6 → 12` with `xOffset: -8`. `dense_forest`,
  `market_square`, `mount_mystery` all shrunk to size 8 (existing content
  already fit indices 0–7).
- `src/World.js` — imports spacing/helpers from `data.js`.
  `_buildBridges` now only creates the turtle↔home bridge. `_addBridge`
  rewritten to derive geometry from `getTurtleBridgeBand` so the visual
  plank and the walkable band can't drift. Water-shader cluster center
  and cloud-plane position retuned `(28,28) → (16,16)`. Beach rim
  retained only for the turtle — on the contiguous landmass a sandy rim
  between two biomes would be a seam that no longer exists.
- `src/Player.js` — `_getIslandCenter`, `_snapToNearestIsland`,
  `_isValidPosition`, `_updateCurrentIsland` all use
  `getIslandWorldPos` instead of hardcoded `* 14`. Old per-pair bridge
  sweep replaced by a single turtle-bridge check.
- `src/Game.js` — initial camera `(14,18,42) → (8,18,30)` for the
  tighter cluster.

### Protocol infrastructure
- `package.json` — version `0.1.0 → 0.2.0`.
- `src/version.js` — single-source-of-truth `VERSION` export.
- `src/main.js` — writes the version into the `#version-display` element
  on load.
- `index.html` — added the `#version-display` chip under the day
  counter.
- `archive/README.md` — protocol and version-bump policy.
- `archive/v0.2.0.md` — this entry.
