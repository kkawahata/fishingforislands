# v0.3.0 — Quest refactor, Phase 1: dialogue & rewards on the quest
Date: 2026-04-22

## Summary
Phase 1 of the Option-B refactor from `docs/quest-refactor-proposal.md`.
Each quest now owns its own dialogue lines and declares its rewards;
the `DIALOGUES` constant shrinks to only the truly-shared lines. This
is a **minor version bump** because it restructures the data model,
though behavior for the player is unchanged.

## What moved

## Editor

The two static "On Start" / "On Complete" dropdowns became a **dialogue
bag editor**: one row per key, with the lines as an editable JSON
textarea. Keys are renameable; add / remove is one click. Works for
the migrated quests out of the box and lets new quests be authored
with arbitrary moment names.

`formatQuestAsJs` emits dialogue arrays inline; the JSON export and
localStorage overlay payloads serialize them as-is. The localStorage
override reconstitution already handles both shapes, so live editing
round-trips cleanly.

## Runtime

`_showDialogueSequence` now guards against non-array input — a missing
quest dialogue becomes an immediate no-op that still fires its
callback, so a typo in the editor can't crash a handler mid-flow.
